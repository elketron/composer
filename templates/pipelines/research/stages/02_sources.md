# 02 · Sources

## Inputs

| | file | for |
|---|---|---|
| working | `01_question/question.md` | what to look for |

## Process

Find sources for each sub-question. Write one page per source: where it is from, what it says that
matters here, how much to trust it.

## Outputs

- `02_sources/<source>.md`, one per source
- `02_sources/index.md`: the sources, by sub-question
