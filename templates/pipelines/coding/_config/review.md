# Review

What a review looks for, most important first.

1. Does it do what the spec says, and only that?
2. Correctness: edge cases, errors, concurrency.
3. Tests: do they cover the spec's checks?
4. Readability: would the next person understand it?

Findings name the file and line, say what goes wrong and when, and suggest a fix.
