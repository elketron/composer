composer app: phone UX, round 2

From trying 0.1.0 on a phone (Android emulator, a server with an orchestrator, a worker and a plain chat). The theme stays as it is; what changes is where things are and how much each screen asks of you.

What got in the way
  • The home screen is the server page. Model name, slots, version and the site chips come first; the sessions you want to continue are below them, at the bottom.
  • New session can't pick an agent or project. It always starts default; an orchestrator needs the TUI.
  • Every tool call and every thought is its own row. One orchestrator turn was 9 rows (thinking · 20 words, open … open, …) before the answer; on a phone that is a screen of noise.
  • Nothing says what is waiting for you. Running sessions, approvals and finished workers look like any other row; you find them by scrolling.
  • Two servers with the same hostname look identical in the switcher (it shows the model, not the address).
  • Pages are hard to reach. Only the site chips on the server page and the book icon in a chat; no search on the phone.
  • Add server: a third of the screen is empty, the form jumps when the keyboard opens, and pasting the link from composer pair still leaves two fields.
  • The project is invisible in the chat on a phone, and the worker's finished state is lost after reconnecting (grey dot).
