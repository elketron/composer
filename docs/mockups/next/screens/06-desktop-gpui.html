GPUI is not a web page. It is two panes and a terminal.

The desktop shell is the real thing: a workspace stripe, one top bar, the TUI in the left pane, a 4px splitter, and the stage as a CEF web pane. Its own focus accent is amber #e0a040; the terminal keeps the TUI's blue. The chat is full-width bands — yours tinted, the agent's raised — so turns separate without a rule between them.
